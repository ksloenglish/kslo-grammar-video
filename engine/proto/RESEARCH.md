# Design-led motion graphics: sources (20 Oct 2026)
- https://webflow.com/blog/animating-with-claude-and-gsap (Cassie Evans, GSAP, 9 Oct 2026): Claude "can't actually create
  video ... it writes code. It builds the scene with web technologies like HTML, SVG, and canvas, with Three.js for anything 3D
  ... A headless browser then steps through the animation in frames, and ffmpeg stitches those frames into an MP4."
  Often rolls its own engine. Options: GSAP (all plugins free), HyperFrames (HeyGen, HTML->video). Taste: "If everything
  moves, nothing stands out ... Good animation does a job. It guides someone's eye, explains how two ideas connect, shows
  that something changed". Learning refs: Emil Kowalski's animation skills, Material Design motion guidelines, Osmo,
  Made With GSAP.
- https://louisedesadeleer.substack.com/p/how-i-make-custom-motion-graphics (21 Apr 2026): Claude Code + Remotion;
  recreate motion graphics from Pinterest/YouTube references; "the bottleneck shifts from technical skill to taste".
- https://www.remotion.dev/license : Remotion free for individuals, for-profit orgs <= 3 employees, non-profit or
  not-for-profit organisations; company licence otherwise.
- https://www.remotion.dev/docs/ai/skills : Remotion Agent Skills for Claude Code etc.
