# Writing an approvable Kayla grammar-video script

## Start with source fidelity and a teachable map

1. Read the teacher's grammar-book pages in full. List the source grammar headings, forms, uses, examples and any vocabulary/context a Hong Kong secondary learner might not know.
2. Ask for the **exact video title** and the featured item list if either is not supplied. Do not infer a unit number or title.
3. Select a small coherent system rather than copying every textbook example. Keep grammar terms accurate; use one representative example per idea where possible.
4. Turn lists into a memorable visual system. In the reference unit, the 2×2 Tense Map turned four lists into PRESENT/PAST × SIMPLE/CONTINUOUS, with yellow dots for whole/fact/finished actions and pink bars for actions in progress.
5. Mark every approved deviation from the book (shortening, a safer/localised example, a needed gloss, or an added quiz) for teacher approval. Do not hide a rewrite in layout work.

**Timing estimate:** start with the measured reference delivery rate of **2.4 words per second**, then add animation/read/quiz holds. This is an estimate only: final duration comes from chosen voice takes and required reading time. The older 2.6 wps estimate and a strict under-five-minute target are superseded.

## Recommended running-order template

Use the sequence below, not every possible scene. Fit it to the actual unit and leave enough time to read.

| Stage / typical range | Purpose | Effective scene types |
|---|---|---|
| L0, 4 s | Brand and title | Logo opening; series + unit title only |
| L1, about 16–18 s | Welcome and promise | Generic reusable intro; title/overview on the left; Kayla name tag |
| Hook, 8–12 s | Create a question answered later | Source speech bubbles or a contrast pair, **with context labels**; question/plot promise |
| Overview map, 10–15 s | Give students the whole system | 2×2 map, colour key, labelled categories |
| Each level card, voice + 1.2 s | Reset attention | LEVEL card with the real grammar point, not a device name |
| Form scene, 7–12 s | Show construction before use | Token/formula blocks: pronoun + auxiliary + verb ending; regular/irregular pair cards |
| Uses, 12–35 s | Explain applications | Numbered rows with icon, labelled use, example sentence, time-word chips; focus dimming and review hold for 3+ rows |
| Diagram/contrast, 8–25 s | Show relation/exception | Timelines, long/short bars, right/wrong pairs, inside/outside story zones, plot-twist comparison |
| T, about 4 s | Refresh attention | Reusable transition between the two broad halves |
| Quiz, 7–9 s each | Retrieval, not passive viewing | Boss-quiz intro; solid blank; 3–2–1; spoken answer, grammar tag and reason |
| Cheat sheet, 8 s + read hold | Consolidate | Map/summary strips and 'Pause & screenshot!' |
| L3, about 10 s; L4, about 6 s | Close and retain | Reusable outro with **real grammar-point** chips; black and silent end card |

For the completed unit this order became: opening → intro → Snow White hook → Tense Map → Levels 1–2 → transition → Levels 3–4 → Boss quiz → cheat sheet → outro → end card. The final allowed duration was 5:19.6 because the design-led review holds made it readable.

## Scene-writing patterns that work

### Make textbook material self-explanatory

Viewers have not read the page. Add a short label above source bubbles ('Someone talks about a favourite story'; 'The same person then sums up what happens in the story'), label chip rows ('Habit words that go with the simple present'), and spell out diagram relationships ('LONG = past continuous', 'SHORT = simple past'). Use a short gloss for a likely unfamiliar word only where it helps the grammar point.

### Present forms and tables as structure, not prose

- Use formula tokens for form: `[am / is / are] + [verb] + [-ing]`, or `walk + -ed → walked` next to measured irregular pairs.
- Use numbered rows for three or more uses. Reveal the row as Kayla says it, dim prior rows, then restore the whole set for review.
- Turn tense relationships into timelines: yellow dots for simple/finished events; pink bars for continuous/in-progress actions; cyan for time/signal words.
- Keep lines that belong together on one visual alignment system. Use a true drawn arrow rather than a missing-glyph Unicode arrow.

### Make vocabulary lists memorable without turning devices into topics

- Group state/non-action verbs by meaning: feelings, thinking, senses, owning.
- Pair each category with a single meaningful icon and a small chip row.
- Use a mnemonic such as **'Give me five!'** only inside the lesson. It can make five uses memorable, but it is not a grammar point and must never appear as a recap/outro/YouTube chapter subject.
- Use a 'No -ing Zone' sign to frame an exception, then give right/wrong sentence pairs and a 'Plot twist' that explains when meaning changes.

### Write fair quizzes

- Give enough wording/context for only one answer. The reference added 'Right now' so *want* rather than *wanted* was required, and 'and saves the planet' so a synopsis needed *flies*.
- Display `___` in planning, but render **one solid blank line** in the final scene. Make answers large and state the reason, not merely the word.
- Write quiz answer tags with a real grammar point plus the useful cue; do not duplicate/redundantly stack tags.

### Write a real recap

Use only the grammar points named in the source pages. A strong recap contains the form/use relationship, not merely devices or slogans. The reference summary used simple present, present continuous, simple past, past continuous, non-action verbs and tenses in stories; it did **not** list Tense Map, Give me five or No -ing Zone as topics.

## What to show the teacher, and in what order

Do not build the final video before the relevant blocking approvals.

1. **Series proposal / options** — concept distinct from the vocab series, Kayla design/voice options, reusable-clips plan, cost approach and generic library scripts.
2. **Single-video plan** — title-only naming, intended length, running order, grammar map/levels, selected examples and caption approach.
3. **Word-for-word body-script table** — for every scene: on-screen content, exactly what Kayla says, Kayla layout/expression, estimated duration, quiz key and a table of changes from the book. Obtain explicit body-script approval before building.
4. **Key visual mockups** — title/header, teaching panel, timeline/formula, quiz, cheat sheet, outro/end card. Resolve logo height, avatar safe area, labels, pill centring and blank-line rules here.
5. **Library clip approval/QA** — record/generate once; verify pronunciation, gestures, neutral endpoints and lip timing before reuse.
6. **Complete key-stills gallery** — show every scene's entrance/busiest/review state as one batched gallery; get explicit approval before a full final render.
7. **Final delivery gate** — finished MP4, English and zh-HK SRTs, YouTube title/description/chapters/tags, and all QA PASS.

Visual changes require still approval first. Implement small audio corrections directly, but re-run final audio/caption/transcript verification before delivery.

## Body-script table fields

Use a source of truth such as `scripts/single_script.py` and generate the approval document from it. Include:

| Field | Why it matters |
|---|---|
| Scene ID and clock position | Links script, scene file, timing and QA evidence |
| Purpose / source point | Guards against silently changing pedagogy |
| On-screen text and labels | Lets the teacher approve self-contained wording, highlights and context |
| Kayla says | Exact spoken text, later used for TTS and captions |
| Kayla layout/expression | Prevents text/avatar collisions and unmotivated reactions |
| Approximate duration | Exposes a rushed section before build |
| Colour/highlight intention | Keeps tense/time-word colour semantics consistent |
| Source change / rationale | Makes teacher approval meaningful |

## Final writing rules

- Address 'K S Lo students'; use British English and British spellings such as *practising*.
- Use single quotation marks for quoted words/sentences in documents and screen copy where typography permits.
- Never write a unit number, episode number or S2 label into title/intro/outro speech.
- Keep examples, grammar terminology and the spoken/on-screen relationship accurate. Highlight only the words being taught.
- Plan all reader-facing holds from the beginning. Do not solve an unreadable scene by shortening the text or speeding Kayla without teacher approval.
